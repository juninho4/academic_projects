# CP1404 Assignment 2 - Song List 2.0 by Juninho Chandra

A Python project with GUI and Console programs that (re)use classes to manage a list of songs to learn.

# Project Reflection

## 1. How long did the entire project (assignment 2) take you?
It took me about 5 hours in the span of 2 days.

## 2. What are you most satisfied with?
Most likely the functionality when clicking a button and considering every case on what should happen.
Getting the program working with the intended features is the most satisfying part of the project.

## 3. What are you least satisfied with?
Probably on the usage of functions, I am still not that familiar on Single Responsibility Principle works.
Most of the time, I'll just use functions when I am using it multiple without considering the principle.

## 4. What worked well in your development process?
The interface of the GUI program and how everything changes when certain event happens.
I tried to mimic everything as much as I can from the assignment demonstration.

## 5. What about your process could be improved the next time you do a project like this?
I would say on how I use the functions properly, I feel like I need to do more refactoring.
There are some tiny parts that I underestimate that needs to be refactored into a separate functions.

## 6. Describe what learning resources you used and how you used them.
I used W3Schools for basic python function revisions, as well as KivyDemos from the repo and official kivy documentation for getting familiar on how kivy works.
But I will always to follow this unit coding format as much as I can, so past practicals are quite essential too.

## 7. Describe the main challenges or obstacles you faced and how you overcame them.
I personally don't like reading, so I just skim-read the entire instruction just to get everything working, but I realized that I need to read instruction from the start.
And it actually helped me a lot on project management and lots of unthinkable thoughts that I missed.

## 8. Briefly describe your experience using classes and if/how they improved your code.
My experience with classes is that they helped my managing multiple instances of the same type extremely well, instead of using a list of list to store them.
Having methods to deal with each object is useful, so that we don't need to make a new function for it.
