# Wildlife Conservation Image Classification

A deep learning image classification project developed for the **DrivenData "Competition Image Classification for Wildlife Conservation"** challenge. The project explores transfer learning, data augmentation, and model ensembling to classify wildlife species from camera trap images.

> This project was completed as part of my Bachelor of Information Technology coursework at James Cook University Singapore.

---

## Overview

The objective of this project was to build an accurate image classification model capable of identifying wildlife species from camera trap images collected for conservation efforts.

The project followed an iterative machine learning workflow, progressing from a baseline model to an optimized ensemble model through experimentation with different architectures and training techniques.

---

## Competition

**DrivenData Competition**

**Competition Image Classification for Wildlife Conservation**

https://www.drivendata.org/competitions/87/competition-image-classification-wildlife-conservation/

The competition focuses on applying computer vision techniques to automate wildlife monitoring, helping conservation researchers process large collections of camera trap images more efficiently.

## Project Workflow

### 1. Baseline Model

- Initial transfer learning model
- Image preprocessing
- Model training
- Performance evaluation

---

### 2. Prediction & Submission

- Generated predictions on the competition test dataset
- Submitted predictions to the DrivenData leaderboard
- Evaluated public leaderboard performance

---

### 3. Model Improvement

Multiple techniques were explored to improve classification accuracy, including:

- Hyperparameter tuning
- Fine-tuning pretrained models
- Training optimization
- Validation improvements

---

### 4. Data Augmentation

Different augmentation strategies were applied to improve model generalization, including:

- Random flips
- Random crops
- Rotation
- Color transformations
- Cutout / Random Erasing
- Image normalization

---

### 5. Ensemble Learning

The final model combines predictions from multiple trained models to improve robustness and leaderboard performance.

Different model versions were trained and evaluated before producing the final ensemble submission.
