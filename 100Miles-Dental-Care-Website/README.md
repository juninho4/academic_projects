# 100Miles Dental Care Website

A responsive multi-page website developed for a fictional dental clinic. The project demonstrates fundamental front-end web development concepts, including semantic HTML, responsive CSS, JavaScript interactivity, and user-friendly navigation.

> This project was completed as part of my Bachelor of Information Technology coursework at James Cook University Singapore.

---

## Overview

The objective of this project was to design and develop a professional website for a dental clinic that provides visitors with information about the clinic, its services, staff members, articles, announcements, and contact details.

The website focuses on usability, responsive design, and clean navigation across desktop and mobile devices.

---

## Features

- Responsive website layout
- Multi-page navigation
- Mobile hamburger menu
- Contact form with client-side validation
- Service information pages
- Staff profiles
- Health articles
- Announcements page
- Image gallery and promotional content

## Key Functionality

### Responsive Navigation

The website includes a mobile-friendly hamburger menu that improves navigation on smaller screen sizes.

### Form Validation

The contact page uses JavaScript to validate user input before form submission, ensuring required fields are completed and phone numbers contain valid numeric values.

### Responsive Design

The layout adapts to different screen sizes using CSS, providing an accessible browsing experience on desktop, tablet, and mobile devices.
